# Instalación en Windows - Página de venta

La página es estática.

## Abrir localmente

```powershell
cd C:\Users\Antonie\Documents\PaginaVenta
.\ABRIR_PAGINA_VENTA.cmd
```

También puedes abrir `index.html` directamente.

## Para registrar prospectos automáticamente

Antes de usar el formulario, inicia el panel de licencias:

```powershell
cd C:\Users\Antonie\Documents\Serial Proyecto
.\INICIAR_TODO_SERIAL.cmd
```
