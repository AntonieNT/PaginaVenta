Privacidad y confianza

La información del negocio se mantiene bajo control del cliente.

El sistema trabaja con datos locales del negocio. Las actualizaciones pueden mejorar pantallas, reglas o estructuras internas, pero no están diseñadas para manipular, vender o borrar la información del cliente de forma remota.

  • Respaldos configurables.
  • Usuarios y roles por responsabilidad.
  • Tickets con datos del negocio y referencia discreta del desarrollador.
  • Avisos de licencia antes de vencer.

Solicitud de licencia

Primero registramos tus datos; después confirmamos pago y activación.

Para dar confianza, la compra se atiende con formulario. Ahí se capturan datos del negocio, datos fiscales si aplican, forma de pago elegida y comprobante cuando ya exista.

1. Conoce e instala

Descarga el instalador oficial y valida que el sistema corresponde a tu operación.

Descargar instalador Ver release oficial

2. Llena la solicitud

El formulario concentra la información necesaria para contactarte, confirmar el plan y recibir comprobante de pago cuando corresponda.

Si el formulario no abre, también puedes pedir seguimiento por WhatsApp desde esta página.

3. Revisamos y enviamos serial

Cuando el comprobante queda validado en el panel interno, autorizamos la licencia y el sistema manda el serial al correo registrado.

No se solicita información sensible de tarjeta por mensaje. Los pagos con tarjeta deben ir por liga formal.

Preguntas frecuentes

Respuestas rápidas para compradores.

¿El sistema puede instalarse en una computadora del negocio?

Sí. La versión local está pensada para instalarse en el equipo del cliente y consumirse desde los dispositivos permitidos en la red del negocio.

¿Cómo se reporta un pago?

El comprador llena el formulario de solicitud, elige forma de pago y adjunta comprobante cuando ya haya realizado la transferencia, depósito o pago acordado.

¿Se puede usar en celular o tablet?

Sí. La interfaz cuenta con modo móvil y modo táctil para pantallas de mostrador o tablets.

¿Qué pasa cuando vence la licencia?

El sistema avisa antes del vencimiento para que el cliente pueda renovar sin interrumpir su operación.

¿Cómo se activa la licencia?

Después de confirmar el pago y los datos del negocio, se envía un serial de activación al correo registrado.
